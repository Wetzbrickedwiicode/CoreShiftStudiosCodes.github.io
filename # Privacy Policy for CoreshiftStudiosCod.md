# Privacy Policy for CoreshiftStudiosCodeChecker

**Last Updated:** 10/9/2026

CoreshiftStudiosCodeChecker ("we", "our", "us") respects your privacy. This policy explains how we handle information when you use our Discord bot.

### 1. Information We Collect
We only process data necessary for the functionality of our bot:
* Discord User IDs and User Tags (to log who uses commands like /validate)
* In-game Roblox analytics linked via our verification logs

### 2. How We Use Information
We use this data solely to run our promotional code validation feature, prevent abuse/explre-use of codes, and log actions for staff review.

### 3. Data Storage and Security
We do not store your personal passwords. Any data sent to Roblox is managed via secure, encrypted tokens. Data is stored through Roblox's official Open Cloud DataStore architecture.

### 4. Third-Party Sharing
We never sell, rent, or distribute user data. Data is shared only with Discord (to process commands) and Roblox (to validate code ownership).
